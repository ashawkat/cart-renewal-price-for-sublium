# Cart Renewal Price for Sublium

Standalone plugin: sync Sublium Subscribe & Save **renewal / subscription totals** to the **cart line price**, without touching plan assignment.

Third-party plugin by Betatech. Not affiliated with Sublium.

See [CONTEXT.md](CONTEXT.md) for full history and constraints.

## Activate

1. Plugins → **Cart Renewal Price for Sublium** → Activate  
2. Leave **Auto Apply Cart Coupon** as-is (separate concerns)

## Safety

Price filters only. No plan stripping. No subscription group changes.
